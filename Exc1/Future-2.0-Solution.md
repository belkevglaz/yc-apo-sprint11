## Проблемные места IT-ландшафта

| Область                       | Проблема                                                                                                                                                       | Последствия                                                                                                                                                          |
|:------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Хранилище данных (DWH)        | Используется устаревший SQL-сервер, который не поддерживает современные технологии и масштабируемость.                                                         | Низкая производительность при обработке больших объёмов данных. Устаревшая архитектура мешает интеграции новых бизнесов и технологий.                                |
| BI-система (Power BI)         | Сложная кастомизация BI-системы поверх DWH замедляет внедрение новых аналитических решений.                                                                    | Увеличивается время на разработку и поддержку аналитических отчётов, что снижает скорость принятия бизнес-решений                                                    |
| Интеграции (Apache kafka)     | Устаревшая шина данных на базе Apache kafka не масштабируется и плохо подходит для интеграции новых бизнесов                                                   | Интеграция новых систем и бизнесов требует много ручной работы и сложной настройки, что увеличивает затраты и время                                                  |
| Клиентский интерфейс          | Используется устаревший интерфейс на Power Builder для работы операторов                                                                                       | Низкая производительность, неудобство для пользователей, невозможность быстрого внесения изменений и масштабирования                                                 |
| Масштабируемость              | Текущие технологии и архитектура не обеспечивают масштабируемости при увеличении объёмов данных                                                                | Увеличение объёмов данных или добавление новых компаний                                                                                                              |
| Работа с медицинскими данными | Медицинские карты, истории болезней и исследования хранятся в DWH, что делает их менее защищёнными и затрудняет их исключение из аналитики                     | Риски утечки конфиденциальных данных, нарушение требований законодательства, необходимость сложной фильтрации для создания витрин данных без медицинской информации. |
| Интеграция новых бизнесов     | Текущая архитектура построена на монолитных решениях, где для добавления новых функций или компаний нужно переписывать большое количество бизнес-логики в DWH. | Увеличиваются затраты на интеграцию новых бизнесов, что снижает гибкость и конкурентоспособность компании                                                            |

## Приоритизация проблем

| Проблема                      | Категория   | Обоснование                                                                                                                                                  |
|:------------------------------|-------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Хранилище данных (DWH)        | Must-have   | Устаревшая версия SQL-сервера напрямую влияет на производительность и скорость работы всей аналитики компании. Это критический узел, требующий модернизации. |
| Масштабируемость              | Must-have   | Отсутствие масштабируемости ограничивает возможность компании развиваться и подключать новые бизнесы                                                         |
| Работа с медицинскими данными | Must-have   | Медицинские данные необходимо изолировать от аналитики для защиты конфиденциальности и соблюдения законодательства.                                          |
| Интеграции (Apache kafka)     | Should-have | Устаревшая шина данных затрудняет интеграцию новых систем. Решение этой проблемы важно, но менее критично                                                    |
| BI-система (Power BI)         | Could-have  | Кастомизация Power BI замедляет аналитику, но модернизация DWH и унификация данных должны решить часть этой проблемы                                         |
| Клиентский интерфейс          | Could-have  | Устаревший интерфейс влияет на удобство работы операторов, но не критичен для достижения стратегических целей                                                |
| Интеграция новых бизнесов     | Won’t-have  | Это следствие основных проблем (масштабируемости, устаревшего DWH). Чпстично или полностью будет решено в при модернизации DWH                               |
